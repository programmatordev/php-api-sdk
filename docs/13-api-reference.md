This reference is split by where methods are available.

- [Resources](05-resources.md): resource classes and endpoint request helpers.
- [Responses](06-responses.md): `Response`, `EntityInterface`, `EnvelopeInterface`, and `Context`.
- [Authentication](07-authentication.md): `AuthBuilder` helpers and custom authentication.
- [HTTP Client](08-http-client.md): `ClientBuilder` helpers and PSR-18/PSR-17 configuration.
- [Cache](09-cache.md): `CacheBuilder` helpers and PSR-6 cache configuration.
- [Logging](10-logging.md): `LoggerBuilder` helpers and PSR-3 logging configuration.
- [Plugins](11-plugins.md): `PluginBuilder` helpers and internal plugin order.
- [Hooks](12-hooks.md): `HookBuilder`, request hooks, response hooks, and hook contexts.
